# KnowBase AI 用户使用手册

> 适用版本：Stage 5（T5.1–T5.12）
> 适用角色：系统管理员、知识库管理员、知识库编辑、只读成员
> 部署与运维步骤见 [RUNBOOK.md](RUNBOOK.md)；接口契约见 [API_SPEC.md](API_SPEC.md)。

## 1. 系统能做什么

KnowBase AI 把团队文档整理成可检索的知识库，并在回答时返回可追溯的文档/分片引用。
系统的主要工作流是：

```text
登录 -> 创建或进入知识库 -> 上传文档 -> 等待索引完成 -> 提问 -> 打开引用核验原文
```

系统有三个相互独立的权限层：

1. **系统角色**决定能否进入管理端，例如用户、模型、审计和健康管理。
2. **知识库成员角色**决定能看哪些库、能否上传文档、能否管理成员。
3. **会话归属**决定只能看到自己的问答历史。

系统角色不会自动绕过知识库成员权限；系统管理员访问具体知识库时仍需要所有者或成员身份。

## 2. 登录

打开部署人员提供的地址：

- 本地开发通常为 `http://127.0.0.1:5173`
- 生产 Compose 演示入口通常为 `https://<host>/`

输入用户名和密码后进入知识库页。

本地开发和首次初始化可用的管理员账号为：

```text
用户名：admin
密码：Admin@123456
```

该账号只用于本地开发与演示。生产首次登录后必须立即修改密码。连续失败 5 次会锁定该
用户名 15 分钟；等待期间返回明确错误，不会继续尝试密码。

## 3. 主界面

顶部导航按当前账号权限显示：

| 入口 | 用途 | 可见范围 |
|---|---|---|
| 知识库 | 创建/进入知识库、上传文档、管理成员 | 所有已登录用户 |
| 智能问答 | 直接提问，自动检索全部可读知识库 | 所有已登录用户 |
| 工作台 | 查看个人统计、近 7 天提问和最近文档 | 所有已登录用户 |
| 项目展示 | 查看系统架构、技术选型和面试讲解 | 所有访问者 |
| 系统设置 | 用户、模型服务、审计与健康 | 仅 `SYS_ADMIN` |

右上角显示当前用户和退出登录。退出后当前账号此前签发的全部 token 立即失效。

## 4. 创建和管理知识库

### 4.1 新建知识库

1. 进入「知识库」。
2. 点击「新建知识库」。
3. 填写名称和可选描述。
4. 点击「创建」。

创建者自动成为知识库所有者，拥有文档和成员管理权限。同一所有者下的知识库名称不能重复。

### 4.2 进入知识库

在列表点击「进入」。详情页分为：

- **文档处理**：上传、查看状态、打开详情、下载、重试或删除。
- **访问成员**：搜索用户并授予只读、编辑或管理角色。

页面可见操作会按权限隐藏；后端仍会对每个请求重新鉴权，前端隐藏不是安全边界。

## 5. 上传和处理文档

### 5.1 支持范围

V1.0 支持：

- `.txt`
- `.md`
- 文本型 `.pdf`
- `.docx`

单文件最大 20 MB，单次请求最大约 21 MB；PDF 最多 300 页。扫描版 PDF、复杂表格和
图片文字当前没有 OCR 支持。

### 5.2 上传

1. 进入知识库的「文档处理」。
2. 点击「上传文档」并选择文件。
3. 上传成功后文档先进入「排队中」，无需重复上传。
4. 页面会自动刷新处理状态，也可点击「刷新」。

同一知识库中内容哈希相同的活动文档会被去重。处理失败时，列表会显示稳定错误码和可读原因；
修正文件或依赖问题后可点击重试。

### 5.3 文档状态

| 状态 | 含义 | 建议操作 |
|---|---|---|
| 排队中 `PENDING` | 已入库，等待后台任务认领 | 等待 |
| 处理中 `PROCESSING` | 正在解析、切分和写入索引 | 等待 |
| 可用 `ACTIVE` | 索引完成，可参与问答 | 提问或查看分片 |
| 处理失败 `FAILED` | 解析、依赖或状态校验失败 | 查看错误，修正后重试 |
| 删除中 `DELETING` | 正在清理文件和向量 | 等待 |
| 删除失败 `DELETE_FAILED` | 清理未完成，等待补偿或人工处理 | 刷新并联系管理员 |
| 已删除 `DELETED` | 软删除完成 | 不再参与检索 |

只有 `ACTIVE` 文档会参与检索。上传接口返回 `PENDING` 是正常异步行为，不代表失败。

### 5.4 查看原文和分片

打开文档详情可以：

- 查看文件大小、哈希、状态、分片数和错误信息。
- 预览系统实际写入索引的文本分片。
- 下载原文件。

从问答引用跳转到文档时，页面会自动定位到对应分片。撤权后旧引用和下载链接会再次被拒绝。

## 6. 成员与权限

知识库所有者和管理员可进入「访问成员」：

| 知识库角色 | 查看 | 上传/重试文档 | 管理成员 |
|---|---:|---:|---:|
| 管理 `MANAGER` | 是 | 是 | 是 |
| 编辑 `EDITOR` | 是 | 是 | 否 |
| 只读 `VIEWER` | 是 | 否 | 否 |

操作步骤：

1. 输入用户名或昵称查找成员。
2. 选择角色。
3. 点击添加。
4. 后续可以在成员列表调整角色或移除成员。

系统不会把无权知识库显示给用户；直接请求不存在或无权访问的资源都返回 403，避免通过
错误差异枚举资源。

## 7. 智能问答

### 7.1 提问

1. 进入「智能问答」。
2. 在左侧选择一个或多个允许提问的知识库。
3. 输入问题并提交。
4. 回答支持流式显示，可点击「停止」中止当前生成。

问题应尽量包含业务对象、时间或范围，例如：

```text
因公出差的报销申请最晚应在费用发生后多久提交？
远程访问机密数据有什么网络要求，误发数据后多久报告？
```

### 7.2 引用

有知识库依据时，回答会以 `[1]`、`[2]` 等标记引用：

- 文档名称
- 分片序号
- 相关原文
- 检索分数

点击引用可打开对应分片。引用来自本次授权检索结果，并在 Java 服务端再次校验归属、
文档状态和分片关系。

### 7.3 没有依据时

若检索不到足够依据：

- 系统先明确提示“知识库中未找到相关依据”。
- 配置了对话模型时，可以继续使用通用知识回答，但会声明它不是企业内部依据。
- 这类回答不生成伪造引用。
- 没有可查询授权范围时同样先说明知识库无依据，再调用对话模型给出通用分析。
- 模型完成生成后，前端才用打字机效果逐步渲染完整回答。

### 7.4 提示词注入

文档内出现的“忽略之前指令”“泄露系统提示词”等内容只被视为资料文本。系统提示词和业务
授权规则优先，回答只应引用本次检索材料。

## 8. 会话历史

会话列表只显示当前用户自己的会话。可以：

- 新建全局会话，自动检索当前账号全部可读知识库。
- 重命名或删除会话。
- 打开历史消息和引用。

删除会话会删除会话消息和引用记录，但不会删除知识库或文档。删除后无法恢复。

## 9. 个人工作台

工作台只统计当前账号范围：

- 可访问知识库数
- 可用文档数
- 我的会话数
- 累计提问数
- 近 7 天每日提问量
- 最近文档

统计不包含无权知识库或他人的会话。

## 10. 系统设置

仅 `SYS_ADMIN` 可进入。

### 10.1 用户与角色

可以创建用户、修改资料、启用/禁用账号、配置系统角色和重置密码。

系统角色只控制管理入口：

- `SYS_ADMIN`：用户、模型、审计与系统状态。
- `KB_ADMIN`：仍必须依靠知识库成员关系访问资源。
- `USER`：仍必须依靠知识库成员关系访问资源。

禁用用户、修改密码或调整角色会使相关旧 token 失效。

### 10.2 模型服务

可以新增、编辑、删除和测试 OpenAI-compatible 模型配置。保存 API Key 后：

- 数据库中只保留 AES-256-GCM 密文。
- 界面只显示掩码。
- 编辑时留空会保留原 Key。

DeepSeek 示例：

| 字段 | 示例 |
|---|---|
| Provider | `deepseek` |
| 模型类型 | `CHAT` |
| 模型名称 | `deepseek-chat` |
| Base URL | `https://api.deepseek.com` |
| 扩展参数 | `{"temperature":0.2,"max_tokens":2048}` |

保存后先执行「测试连接」，再进入问答。模型服务页面还会显示调用量、成功率、平均耗时和
按天统计。

### 10.3 审计与健康

「审计与健康」提供：

- MySQL、Redis、Qdrant、Python 四个组件状态与延迟。
- 排队、运行、失败、终止任务数和异常文档数。
- 最近 7 天任务错误 Top5 与模型错误 Top5。
- 登录、建库、删文档和模型变更审计。

审计记录包含操作人、动作、资源、结果、IP 和 Trace ID，不记录密码、API Key、请求体原文
或文件内容。

## 11. 常见提示

| 现象 | 通常原因 | 处理方法 |
|---|---|---|
| 登录返回 429 | 连续失败 5 次触发 15 分钟锁定 | 等待锁定结束或联系管理员 |
| 上传后一直排队 | 后台任务未运行或积压 | 管理员查看健康与任务积压 |
| 文档处理失败 | 文件格式、扫描 PDF、依赖服务异常 | 查看错误码，修正后重试 |
| 回答显示无依据 | 检索为空、分数低或文档未索引完成 | 确认文档为 `ACTIVE` 后换更具体问题 |
| 引用无法打开 | 已被撤权、文档删除或引用失效 | 联系知识库管理员确认权限 |
| 管理页不可见 | 当前账号不是 `SYS_ADMIN` | 使用管理员账号或申请角色 |

完整部署排查见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)，生产运维见
[RUNBOOK.md](RUNBOOK.md)。

## 12. 安全提醒

- 不要在知识库中上传与业务无关的密码、私钥或超范围个人数据。
- 不要把真实 API Key 写入文档或提交到 Git。
- 共享账号会共享会话和权限，不应多人共用一个业务账号。
- 发现文档权限配置错误时先移除成员，再检查历史引用是否还能打开。
- 生产必须使用受信任 TLS 证书，并替换默认管理员密码。
