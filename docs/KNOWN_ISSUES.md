# 已知问题与改进估算

> 任务：T5.12
> 日期：2026-10-31
> 每条均记录当前表现、影响和大概所需时间。估算按单人熟悉本仓库的净工作时间计算。

## K-01 Docker 运行时验收被环境阻断

**当前表现**：`docker version` 返回
`permission denied while trying to connect ... docker_engine`；Testcontainers 也无法打开
Docker named pipe。T5.4、T5.7、T5.8 的容器运行验收未执行。

**影响**：主干跨容器 IT、备份恢复和干净环境启动仍属于未验证风险；代码和配置虽已编译，
不能据此宣称生产容器链路已通过。

**大概需要多久**：修复 Docker daemon/权限后，T5.4 约 1–2 小时，T5.7 恢复演练约 1–2 小时，
T5.8 干净环境验收约 1–2 小时。

## K-02 备份脚本缺少自动化一致性停顿

**当前表现**：脚本可以分别备份 MySQL、上传卷和 Qdrant snapshot，但不会自行停止
Nginx/backend。运行手册要求先手工停止入口和业务后端。

**影响**：如果维护人员直接在有写入时运行，数据库、文件和向量可能来自略微不同的时间点。

**大概需要多久**：在脚本内增加停服、`finally` 自动恢复、超时和退出码处理，约 2–4 小时；
实际演练另需 1–2 小时。

## K-03 Embedding 仍是本地哈希实现

**当前表现**：真实评估使用 `local-hash-v1`，可重复、无需付费，但不具备真实语义泛化；
同义表达和跨领域问题可能漏检。

**影响**：当前 Recall@5 97.50% 只能在固定短文档和该 Embedding 条件下引用，不能代表
真实企业语料效果。

**大概需要多久**：接入真实 Embedding 并重建 collection 约 0.5–1 天；重跑评估、记录
成本和调整阈值约 0.5–1 天。

## K-04 M04 多文档召回不完整

**当前表现**：M04 同时期望“数据分级”和“远程办公”两份文档，实际回答只覆盖一份，
文档级 Recall@5 为 50%；已返回引用的正确率仍为 100%。

**影响**：多文档综合题可能漏掉必要条件，而引用正确率表面仍很高。

**大概需要多久**：先做分片/检索调优与查询改写约 1–2 天；若引入混合检索和 reranker，
约 3–5 天，并需重新建立评估基线。

## K-05 前端 Element Plus 包体过大

**当前表现**：生产构建中 Element Plus vendor chunk 为 940.67 kB，超过 Vite 800 kB 警告线。

**影响**：首次加载和弱网体验受影响，尤其是移动网络；功能本身不受影响。

**大概需要多久**：改为按需引入或配置更细的 manual chunks，约 0.5–1 天；完成浏览器回归
另需 2–4 小时。

## K-06 PDF 不支持 OCR 和复杂版面

**当前表现**：支持文本型 PDF，但扫描件、图片文字、复杂表格和跨页结构无法可靠解析。

**影响**：企业大量历史 PDF 可能上传成功但无有效文本或丢失表格语义。

**大概需要多久**：接入 OCR 与表格解析、隔离重任务队列、增加页级失败记录约 1–2 周；
若要求版面保真和表格问答，需更长。

## K-07 生产环境仍是单机低可用架构

**当前表现**：MySQL、Redis、Qdrant、Java、Python 都在单机 Compose；MySQL 流量在同一个
私有 Docker 网络内显式关闭 TLS；没有 WAF、托管密钥库和 volume 静态加密。

**影响**：主机故障会导致整体不可用；跨主机部署前必须补充数据库 TLS、网络隔离和密钥管理，
否则不满足更严格的生产安全要求。

**大概需要多久**：迁移到托管 MySQL/Redis/Qdrant、对象存储和外部密钥管理，约 1–2 周；
若增加多实例、高可用和演练，约 3–4 周。

## K-08 缺少并发和容量基线

**当前表现**：RAG 延迟是单用户顺序请求；没有并发用户、长文档、队列堆积和模型限流的
压测报告。

**影响**：无法给出可靠并发容量、扩容阈值和 SLA 承诺。

**大概需要多久**：设计场景与指标 0.5 天，压测脚本和监控 1–2 天，执行与调优 2–5 天。

## K-09 引用召回用最终引用近似

**当前表现**：评估器通过最终 citations 计算 Recall@5，没有独立检索调试接口。

**影响**：检索到了但模型未引用的正确结果会拉低 Recall，指标偏保守，不能精确区分检索器
和生成器问题。

**大概需要多久**：增加仅在评估环境可用的检索调试输出并做权限隔离，约 0.5–1 天；
重跑全部基线约 2–4 小时。
